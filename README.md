Developed a Retrieval-Augmented GeneraNon (RAG) based system to enable question answering from PDF documents. Implemented text extraction using PyMuPDF and OCR with Tesseract to process both digital and scanned PDFs. Generated semantic embeddings using HuggingFace BGE model and stored them in a FAISS vector database for similarity search. Integrated Groq API and built a Streamlit web interface for real-time document chat.
